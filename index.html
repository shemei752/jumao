三、获取号码

/api/get_mobile?token=xxxx&project_id=项目ID

传参方式：Get

# 参数名 含义 类型 说明
1 token 通过API登录后获取到的token String 必填
2 project_id 项目ID int 必填
3 operator 运营商（不填或0=不限，1=实卡，2=虚拟） int 选填
4 phone_num 指定号码或号段，传入完整手机号即为指定取号，传入开头前几位即为指定号段 int 选填
5 province 省份筛选：如北京（不带'省'字） String 选填
